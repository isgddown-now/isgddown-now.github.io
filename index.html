About isGDDown

isGDDown is an independent Geometry Dash server status checker. It uses its own backend to check the availability of selected online services and help players investigate connection problems.

The results describe only the services tested by this checker. A successful check does not guarantee that every Geometry Dash feature is working, and a failed check may affect only one service.

isGDDown is a community-made project and is not affiliated with or endorsed by RobTop Games.

Frequently Asked Questions

How do I know if Geometry Dash servers are down?

isGDDown checks selected online services. If all checks succeed, the tested services appear operational. If some checks fail, Geometry Dash may be partially affected. These checks do not guarantee the status of every game feature.

How does isGDDown check server status?

The website requests status results from its own backend, which checks selected Geometry Dash online services. The results are independent checks and are not an official RobTop Games status feed.

Why can't I connect to Geometry Dash?

Connection problems can be caused by server-side issues, an internet connection problem, or an issue affecting a particular online service. If the checks succeed, try checking your connection and testing again later.

Why am I getting a “Save Failed” error?

A save error does not necessarily mean all Geometry Dash servers are down. It can have several causes. Check your connection and consult reliable Geometry Dash support information if the problem continues.

Is isGDDown an official RobTop status checker?

No. isGDDown is an independent, community-made project and is not affiliated with or endorsed by RobTop Games.
