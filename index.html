isGDDown is an independent Geometry Dash server status checker. It uses its own backend to check the availability of online services and help players investigate connection problems. This community-made project is not affiliated with RobTop Games.

Frequently Asked Questions

How do I know if Geometry Dash servers are down?

isGDDown checks several selected online services. If all checks succeed, the tested services appear operational. If some checks fail, some services may be experiencing problems. If all checks fail, the tested services may be unavailable.

How does isGDDown check server status?

The website requests a status report from its own backend. The backend checks selected Geometry Dash online services. Results are independent checks and are not an official RobTop Games status feed.

Why can't I connect to Geometry Dash?

Connection problems can have different causes, including server-side issues, internet connectivity, or problems with a particular online service. If the checks are successful, try checking your connection and testing again later.

Why am I getting a "Save Failed" error?

A save error does not necessarily mean all Geometry Dash servers are down. It may have several causes. Check that your connection is working and consult reliable Geometry Dash support information if the problem continues.

Is isGDDown an official RobTop status checker?

No. isGDDown is an independent, fan-made project. It is not affiliated with or endorsed by RobTop Games.
